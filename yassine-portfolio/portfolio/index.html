02 · Automation & Integration

Smart Process Station: industrial automation platform

Personal projectIn progress · since Nov 2026
ESP32-S3 field device⇄Modbus TCP · versioned register map⇄Python controller · state machine→MQTT telemetry
  • ESP32-S3 field device for a simulated conveyor, serving a versioned Modbus TCP register map to a Python controller that runs the state machine, interlocks and alarms.
  • Inputs validated at the integration boundary: out-of-range writes are rejected with a protocol exception before being stored.
  • Heartbeat failsafe and task watchdog, verified on hardware by fault injection.
  • CI with GitHub Actions: unit tests, end-to-end acceptance tests against an emulator built from the firmware's own code, static analysis and firmware build.

03 · AI & Software Engineering

Supply Chain Intelligence Platform: agentic AI for operational documents

Personal project2026
Question→LangGraph router→SQL · documents · Neo4j graph→Pydantic JSON→Validation→Answer or refusal
  • AI agent that answers operational questions such as "why is supplier Y late?" by querying PostgreSQL, searching about 2,700 incident and delay reports and traversing a Neo4j graph, using local LLMs.
  • The LLM only routes and picks tools; deterministic code assembles the facts into a typed Pydantic/JSON schema for downstream systems.
  • Validation layer checks every claim against its source (figures against SQL, causes against documents) and downgrades or refuses unsupported answers; every check is mutation-tested.
  • Streamlit UI shows each tool call with its evidence; Grafana monitors outcomes, latency and validation pass rate.
100%Routing accuracy on the dev and held-out sets
80–100%Correct outcomes against ground truth
~2,700Incident and delay reports searchable by the agent

Evaluated on a synthetic freight-company dataset (~23,000 rows, 11,900 graph nodes, 7 planted root causes), not a production deployment.
